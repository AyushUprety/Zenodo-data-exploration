# Fitbit Activity and Sleep Analysis

An exploratory analysis of fitness-tracker data covering daily activity, hourly steps, sleep, and weight logs.

The project narrows a larger collection of files to four core datasets, cleans and combines them, and documents the analysis as a reproducible R Markdown report.

## Questions explored

- What daily activity patterns appear across participants?
- How do steps and calorie burn change by day and hour?
- What relationships appear between activity and sleep?
- How might these patterns inform health-tech product decisions?

## Workflow

1. Import and profile the selected datasets.
2. Remove duplicates and standardize dates and columns.
3. Join activity and sleep records where appropriate.
4. Aggregate daily and hourly behavior.
5. Visualize patterns and document limitations.

## Tools

R, RStudio, R Markdown, data transformation, descriptive statistics, and visualization.

## Data scope

The analysis uses daily activity, hourly step, sleep-day, and weight-log tables sourced from a publicly shared fitness-tracker dataset on Zenodo. Results are descriptive and should not be interpreted as medical guidance or population-level evidence.
